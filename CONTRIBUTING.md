# Contribuindo com o OrkMind

Contributions in English are welcome. Part of the code comments and documentation is written in
Brazilian Portuguese, and a clear technical contribution in English will never be turned away
for language alone. The guides below are in Brazilian Portuguese today.

> **Nada entra sem evidência executável.** Toda mudança de comportamento vem com o comando que a
> comprova, e o comando roda nesta árvore.

## Um guia por tarefa

| Guia | Use quando |
| --- | --- |
| [O que contribuir](docs/contribuir/o-que-contribuir.md) | Você quer saber se abre discussão, issue ou PR |
| [Desenvolvimento local](docs/contribuir/desenvolvimento-local.md) | Você vai clonar, instalar os extras e subir o PostgreSQL com pgvector |
| [Testes](docs/contribuir/testes.md) | Você quer saber o que rodar, o que precisa de banco e se uma falha é sua |
| [Documentação](docs/contribuir/documentacao.md) | Você vai mexer em texto: onde cada doc mora e como conferir |
| [Lint e estilo](docs/contribuir/lint-e-estilo.md) | Você quer o estilo de código e o que o ruff confere |
| [Pull request](docs/contribuir/pull-request.md) | Você vai abrir o PR: descrição, prova, checks do CI e commits |
| [Triagem](docs/contribuir/triagem.md) | Você quer entender rótulos, primeira issue e prazo de resposta |
| [Versões e publicação](docs/contribuir/versoes-e-publicacao.md) | Você quer saber como sai uma versão; publicar é ato do mantenedor |

## O caminho curto

1. Escolha discussão, issue ou PR em [o que contribuir](docs/contribuir/o-que-contribuir.md).
2. Prepare o ambiente pelo [desenvolvimento local](docs/contribuir/desenvolvimento-local.md).
3. Rode o que [testes](docs/contribuir/testes.md) lista e cole a saída no PR.

## Também

- Vulnerabilidade: nunca em issue pública. Ver [SECURITY.md](SECURITY.md).
- Convivência: [código de conduta](CODE_OF_CONDUCT.md).
- Licença: ao contribuir, você concorda que a sua contribuição é distribuída sob a
  [licença MIT](LICENSE).
